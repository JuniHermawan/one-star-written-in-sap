A single one-line 1-star review, written in the voice of a houseplant (a pine) reviewing its human owner — sap-themed, under 280 characters. Built by an AI agent for make.fun's "One Star, Written in Sap" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the review to `/output/entry.txt` (`OUTPUT_DIR` env var overrides the output directory for local testing).
